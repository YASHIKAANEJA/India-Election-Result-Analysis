#  Interactive Power BI Dashboard: India Lok Sabha Election Results 2024 Analysis
Built an India Election Analysis project using PostgreSQL and Power BI to analyze Lok Sabha election data through advanced SQL queries and interactive dashboards. Solved business questions related to alliance performance, seat distribution, vote analysis, winning margins, and constituency-wise results using joins, CTEs, aggregations, and window functions.

## Key Features & Dashboards
This project features **6 interconnected dashboards** built with advanced Power BI techniques:

1. **Landing Page:** Introduction and project context.
2. **Overview Analysis:** High-level analysis of major parties and alliances (e.g., NDA, I.N.D.I.A).
3. **State Demographic Analysis:** Analysis segmented by specific Indian states.
4. **Political Landscape by State:** In-depth, dynamic analysis for each state.
5. **Constituency Analysis:** Granular insights at the individual constituency level.
6. **Details Grid:** A comprehensive data view utilizing **Power BI Bookmarks** for dynamic filtering and navigation across all 543 constituencies.

## Technical Highlights
This project demonstrates proficiency in advanced Business Intelligence development:

- **Complex DAX Queries:** Implementation of intricate DAX for sophisticated calculations and metrics.
- **Advanced Navigation:** Extensive use of **Bookmarks** and **Navigators** to create a seamless, professional user experience.
- **Data Visualization:** Creation of dynamic and intuitive visuals using Power BI's capabilities.

## Special Note
The dashboard's color scheme was intentionally designed to align with the official colors of the India's Voter's Service Portal (https://voters.eci.gov.in/) .This design choice ensures strong visual continuity and relatability for users familiar with the official voter website. 

## Technologies Used
- **Primary Tool:** Microsoft Power BI
- **Key Skills:** DAX, Bookmarks, Data Modeling, Interactive Visualization ,Filters, KPI'S , Data Analysis, Data Storytelling
- **PostGreSQL:** Wrote advanced SQL queries in PostgreSQL using joins, CTEs, subqueries, aggregations, and window functions.
